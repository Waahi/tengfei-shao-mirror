# Tengfei Shao — GitHub Pages mirror

Mirror: https://waahi.github.io/tengfeishao/

Main website: https://tengfeishao.com/

This mirror uses the published Sites version 65 from 27 September 2026 (Japan time).
The page, portrait, and particle interactions are preserved. Inter font files are
served locally under `assets/fonts/`; their SIL Open Font License is included.
The canonical URL continues to identify the main website.

## Publishing

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps the prepared
static files intact. Push updates to `main` to trigger publication; no application
build or server is required.

This is a snapshot mirror. Updating the original Sites website does not
automatically synchronize this repository. Keep asset URLs relative so they work
under the `/tengfeishao/` project path.
